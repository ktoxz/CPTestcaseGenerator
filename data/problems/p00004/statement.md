# Triangle Classification

- CodeNet ID: `p00004`
- Dataset: `AIZU`
- Time limit: `1000 ms`
- Memory limit: `131072 KB`

Given the coordinates of three points, determine whether they form a valid
triangle. The input consists of six real numbers: `x1 y1 x2 y2 x3 y3`.

## Input

```text
0 0 1 0 0 1
```

## Output

```text
1
```
