# AtCoder Beginner Contest 179 - A x B + C

- CodeNet ID: `p02548`
- Dataset: `AtCoder`
- Time limit: `2000 ms`
- Memory limit: `1048576 KB`

Score : 300 points

## Problem Statement

Given is a positive integer N. How many tuples (A,B,C) of positive integers satisfy A \times B + C = N?

## Constraints

-  2 \leq N \leq 10^6

- All values in input are integers.

## Input

Input is given from Standard Input in the following format:
```text
N
```

## Output

Print the answer.

## Sample Input 1
```text
3
```

## Output for the Sample Input 1
```text
3
```

There are 3 tuples of integers that satisfy A \times B + C = 3: (A, B, C) = (1, 1, 2), (1, 2, 1), (2, 1, 1).

## Sample Input 2
```text
100
```

## Output for the Sample Input 2
```text
473
```

## Sample Input 3
```text
1000000
```

## Output for the Sample Input 3
```text
13969985
```
