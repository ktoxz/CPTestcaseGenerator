# Codeforces Div.4 dataset: 1352B–C (20:20)

This bundle contains two problems from Codeforces Round #640 (Div. 4):

- `cf1352b`: 20 Accepted and 20 Non-Accepted C++ submissions.
- `cf1352c`: 20 Accepted and 20 Non-Accepted C++ submissions.

Each problem directory contains:

- `statement.md`: the problem statement.
- `metadata.json`: Codeforces metadata and public examples.
- `oracle/sources/Accepted`: accepted submissions.
- `oracle/sources/NonAccepted`: incorrect submissions.
- `oracle/manifest.json`: labels, paths, and SHA-256 hashes.
- `oracle/provenance.json`: source and deterministic selection policy.

The sources come from DeepMind CodeContests. The upstream dataset describes
these pools as correct and incorrect human submissions. Every selected source
is unique and passes a local GNU++17 syntax/compile check; the Non-Accepted
label is preserved from the dataset rather than re-inferred locally.
