# Prime Numbers II

- CodeNet ID: `p00044`
- Dataset: `AIZU`
- Time limit: `1000 ms`
- Memory limit: `131072 KB`

A prime number is an integer greater than 1 that can only be divided by itself or 1. For example, 2 is a prime number because it can only be divided by 2 and 1, but 12 is not a prime number because, in addition to 12 and 1, it can be divided by 2, 3, 4, and 6.

Given an integer $n$, create a program that outputs the largest prime number smaller than $n$ and the smallest prime number larger than $n$.

## Input

Multiple datasets are given. For each dataset, $n$ ($3 \le n \le 50,000$) is given on one line.

The number of datasets does not exceed 50.

## Output

For each dataset, output the largest prime number smaller than $n$ and the smallest prime number larger than $n$, separated by a single space, on one line.

## Sample Input 1

```text
19
3517
```

## Output for the Sample Input 1

```text
17 23
3511 3527
```
